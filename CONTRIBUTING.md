# Contributing

Thanks for helping improve this plugin.

Keep changes focused and include a short elevator pitch in your pull request: what changed, why it matters, and how you verified it. For code changes, add or update tests when the behavior can be checked without live App Store Connect credentials. For release workflow changes, update the skill, README, and field map together so Codex has the same operating model as the scripts.

Do not commit App Store Connect API keys, `.p8` files, app binaries, screenshots from unreleased apps, or any customer/private release metadata. Use fixtures with invented IDs and copy.
